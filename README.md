# My DIY

Сборник прошивок и вспомогательных библиотек на C/C++ для платформы Arduino.
В одном репозитории — несколько самостоятельных проектов, использующих общий
набор переиспользуемых модулей.

## Состав репозитория

```
arduino/
├── automatic-watering/   — система автоматического полива растений
├── lego-tractor/         — радиоуправляемый трактор из LEGO Technic
├── nixie-clock/          — часы на газоразрядных индикаторах
└── libraries/            — переиспользуемые Arduino-библиотеки
    ├── ArduButton/       — тактовая кнопка с антидребезгом
    ├── ArduLog/          — простой логгер с уровнями
    └── ArduTimer/        — программный таймер на millis()
```

## Проекты

### automatic-watering

Прошивка автополива комнатных растений на Arduino Nano.

Возможности:
- периодическое включение помпы по таймеру (интервал и длительность настраиваются);
- мастер настройки на три тактовые кнопки (`SET`, `LEFT`, `RIGHT`) с поддержкой
  клика и удержания;
- хранение параметров в EEPROM с защитой CRC-32 от «мусора» при первом запуске
  или повреждении памяти;
- LCD 16×2 (I²C, адрес `0x3F`) с обратным отсчётом до следующего полива и
  анимацией лейки во время работы помпы;
- автоматическое гашение подсветки LCD по таймауту бездействия;
- опрос кнопок по прерыванию `Timer1` — реакция не теряется при блокирующих
  операциях в `loop()`.

Управление:

| Кнопка  | Клик                               | Удержание                                                     |
|---------|------------------------------------|---------------------------------------------------------------|
| `SET`   | следующий шаг мастера настройки    | вход/выход в режим настройки (сохранение параметров в EEPROM) |
| `LEFT`  | уменьшение значения в текущем поле | сброс таймера до следующего полива                            |
| `RIGHT` | увеличение значения в текущем поле | принудительное включение помпы                                |

Зависимости: `LiquidCrystal_I2C`, `TimerOne`, `ArduLog`, `ArduButton`, `ArduTimer`.

### lego-tractor

Прошивка радиоуправляемого трактора, собранного из LEGO Technic, на базе
Arduino и приёмника FlySky (протокол iBUS).

Возможности:
- управление двумя моторами через драйвер с PWM (танковая схема: смешивание
  стиков `X` и `Y` в скорости левого и правого борта);
- мёртвая зона по центру стика и компенсация перекоса редуктора правого борта;
- переключение фар по тумблеру;
- мониторинг напряжения батареи с цветовой индикацией (зелёный/жёлтый/красный)
  и телеметрией обратно на пульт через iBUS;
- блокировка движения при разряде батареи (`< 6.0 В`).

Зависимости: `IBusBM`.

### nixie-clock

Часы на четырёх газоразрядных индикаторах ИН-12/ИН-14, основано на проекте
[Алекса Гайвера](https://github.com/AlexGyver/NixieClock_v2).

Возможности:
- динамическая индикация цифр через прерывание `Timer2` с CRT-гамма-коррекцией
  PWM для линейного восприятия яркости;
- RTC `DS3231` (I²C) — синхронизация времени раз в 15 минут, восстановление
  времени после потери питания;
- шесть визуальных эффектов смены цифр: затухание, перемотка цифр, перемотка
  по катодам, «поезд», «резинка»;
- защита от отравления катодов (anti-poisoning) каждые 15 минут;
- ночной режим: автоматическое снижение яркости индикаторов, точек и подсветки
  в заданном временном окне (`23:00`–`07:00`);
- режимы подсветки: «дыхание», максимум, выключена;
- случайные «глитчи» (моргание разряда) с настраиваемыми интервалами;
- управление тремя кнопками; настройки сохраняются в EEPROM.

Зависимости: `Wire`, `RTClib`, `EEPROM`.

## Библиотеки

Все библиотеки находятся в каталоге `libraries/` и оформлены по стандарту
Arduino (есть `library.properties` и `keywords.txt`).

### ArduButton

Обёртка над тактовой кнопкой с подавлением дребезга и распознаванием клика
и удержания. Работает с `INPUT_PULLUP`.

```cpp
#include <ArduButton.h>

ArduButton button(7);

void setup() {
  pinMode(7, INPUT_PULLUP);
}

void loop() {
  button.update();
  if (button.isClicked()) { /* короткое нажатие */ }
  if (button.isHeld())    { /* удержание */ }
}
```

Настраиваются таймауты антидребезга и удержания
(`setDebounceTimeoutMillis`, `setHoldTimeoutMillis`).
Метод `update()` рекомендуется вызывать по прерыванию таймера, чтобы реакция
кнопок не зависела от блокировок в `loop()`.

### ArduTimer

Программный таймер на `millis()` с корректной работой при переполнении
счётчика (раз в ~49.7 суток).

```cpp
#include <ArduTimer.h>

ArduTimer blinkTimer(500);

void loop() {
  if (blinkTimer.isWentOff()) {
    /* действие раз в 500 мс */
  }
}
```

Поддерживает изменение интервала на лету (`setIntervalMillis`), получение
оставшегося времени (`getRemainingTimeMillis`) и сброс (`reset`). При
последовательных пропусках срабатываний интервал «догоняет» текущее время
без накопления ошибки.

### ArduLog

Простой логгер с уровнями `TRACE`, `DEBUG`, `INFO`, `WARN`, `ERROR` (+ `OFF`).
Формат записи: `ЧЧ:ММ:СС.ммм УРОВЕНЬ ИМЯ - сообщение`.

```cpp
#include <ArduLog.h>

ArduLogger logger("Main", ArduLogLevel::INFO);

void setup() {
  Serial.begin(9600);
  logger.info("Started");
}
```

## Сборка и заливка

Каждый проект — самостоятельный Arduino sketch (`.ino`).

1. Установите [Arduino IDE](https://www.arduino.cc/en/software) или
   [Arduino CLI](https://arduino.github.io/arduino-cli/).
2. Скопируйте папки из `libraries/` в каталог пользовательских библиотек
   Arduino IDE (обычно `~/Arduino/libraries/` или `Documents/Arduino/libraries/`),
   либо настройте `sketchbook.path` так, чтобы корень репозитория стал
   sketchbook'ом — тогда библиотеки подхватятся автоматически.
3. Установите внешние зависимости конкретного проекта через Library Manager
   (см. раздел «Проекты» выше).
4. Откройте `.ino` нужного проекта, выберите целевую плату/порт и выполните
   `Upload`.

Пример для Arduino CLI:

```bash
arduino-cli compile --fqbn arduino:avr:nano automatic-watering
arduino-cli upload  --fqbn arduino:avr:nano -p COM3 automatic-watering
```
